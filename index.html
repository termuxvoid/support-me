SEC 01 What is TermuxVoid?

$ echo "why does termuxvoid exist ?"

TermuxVoid is an unofficial custom repository for Termux, offering extra security tools for ethical hacking, bug bounty, cyber security and reverse engineering that aren’t in the official repositories. The same tools ship as both an APT (dpkg) and a Pacman repository, compiled natively for Android.

Every tool is built and maintained by one developer. No company, no funding, no paywall; just an open project for the security research community under the BSD-3-Clause license.

Keeping both repositories compiled, patched and served 24/7 costs real money and real time. That’s where you come in.

SEC 05 Questions people ask

+ Is TermuxVoid really free?

Yes. The repository and every tool in it are open source under the BSD-3-Clause license. It will always be free to install and use; support is optional and never required.

+ Where does my money go?

Every contribution goes toward build infrastructure, hosting and bandwidth for both the APT and Pacman repositories, and compensating the developer’s time. Nothing is hidden: it funds the repo directly.

+ I can’t donate. How else can I help?
  • Star the repository
  • Share TermuxVoid with the community
  • Report broken packages on GitHub Issues
  • Request tools you’d like to see added
+ Do supporters get perks or priority?

No paywalled features: tool requests and bug reports are open to everyone. That’s the deal: support is a thank-you, not a transaction. Supporters do get a personal thank-you and shout-outs in releases.

+ How do I reach the developer?

Telegram @nullxvoid, email termuxvoid@gmail.com, or GitHub Issues.
